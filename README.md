# Fcarrent — Car Rental Website

A responsive car rental website built with HTML, CSS, and JavaScript.

## Live Demo
[Open Fcarrent](https://akhmed-nanotech.github.io/Fcarrent/)

## Features
- Responsive website layout
- English and Russian language support
- Car selection and booking request form
- Pickup and return date fields
- Booking notifications through Telegram
- Cloudflare Worker integration

## Technologies
- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Cloudflare Workers
- Telegram Bot API

## Project Purpose
This personal project demonstrates frontend development, form handling, API integration, and booking workflow automation.
